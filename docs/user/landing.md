# Landing page

Get started opens the RepoDesk self-hosting guide. Source opens the product repository.
How it works jumps to the workflow. The mobile menu closes after selecting a section.
FAQ rows open with click, Enter or Space. The conversation is an illustration and
does not submit a task or show live progress.

## Example scenarios

The Telegram-style walkthrough starts with **Code Q&A**, a read-only question and
an example explanation. Select **Fix an issue** for a spacing request and proposed
pull request, or **PR review** for a review request and suggested feedback.
Every request, response and result is illustrative; no repository is queried,
no checks are actually run by the demo, and nothing is submitted or merged.

Click or tap a scenario to select it. With a keyboard, Tab enters the selected tab;
Left/Right Arrow selects the previous/next scenario and wraps at either end.
Home/End selects the first/last scenario. Enter and Space also activate a focused
tab. Tab then reaches the selected example panel; Shift+Tab returns to its tab.
Screen readers receive the selected state, panel name and example disclaimer.

Switching examples reserves space for the longest scenario, keeping the following
sections in place. The controls work on mobile and desktop without animation and
respect the page’s reduced-motion setting.
